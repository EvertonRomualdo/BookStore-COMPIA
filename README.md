# 🧠 COMPIA Editora

Acesse: https://bookstore-compia-production.up.railway.app/

A COMPIA é uma plataforma de e-commerce literário focada em conectar a excelência da pesquisa acadêmica com o mercado de tecnologia global. O sistema oferece a venda de livros e e-books especializados em áreas de ponta, como Inteligência Artificial, Arquitetura de Software, Blockchain e Cibersegurança.

Este repositório contém a aplicação Frontend (Interface do Usuário), construída com rigor técnico para entregar alta performance, responsividade e uma experiência de usuário (UX) moderna.

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as ferramentas mais modernas do ecossistema front-end:

* **React** com **TypeScript**: Tipagem estática e componentização escalável.
* **Tailwind CSS**: Estilização utilitária, responsiva e de fácil manutenção.
* **React Router DOM**: Gerenciamento de rotas para uma navegação fluida (Single Page Application).
* **React Hook Form + Zod**: Gerenciamento de estado de formulários e validação robusta de esquemas.
* **Lucide React**: Biblioteca de ícones leves e customizáveis.
* **LocalStorage API**: Por dificuldades técnicas, foi utilizada nessa primeira versão o LocalStorage para simular a persistência de banco de dados e APIs durante a fase de prototipagem (sessão de usuários, cadastros e histórico).

## 🚀 Como executar o projeto localmente

Para rodar este projeto em sua própria máquina, siga as instruções abaixo.

### Pré-requisitos
Certifique-se de ter o **Node.js** (versão 18 ou superior) e o **Git** instalados no seu ambiente de desenvolvimento.

### Passo a Passo

**1. Clone o repositório**
Abra o seu terminal e clone o projeto usando o Git:
`[git clone https://github.com/EvertonRomualdo/BookStore-COMPIA.git`

**2. Acesse a pasta do Frontend**
Navegue até o diretório exato onde a aplicação front-end está localizada:
`cd frontend/compia`

**3. Instale as dependências**
Faça o download de todos os pacotes necessários para a aplicação funcionar:
`npm install`

**4. Inicie o servidor de desenvolvimento**
Rode o comando de inicialização:
`npm run dev`

**5. Acesse no Navegador**
Após executar o comando acima, o terminal exibirá um endereço local (geralmente `http://localhost:5173`). Basta clicar neste link ou colá-lo no seu navegador para utilizar a COMPIA Editora.
